# Brasa Lancheria

Site demonstrativo de uma lancheria, em português, com cardápio, carrinho, ajuste de quantidades e cópia do resumo do pedido.

Marca, cardápio e preços fictícios. Nenhum pedido é enviado e não há cobrança.

## Publicação

Site estático em HTML, CSS e JavaScript. O GitHub Pages publica a raiz da branch `main`. O arquivo `.nojekyll` desativa o processamento do Jekyll.

Os caminhos de imagens, fontes, estilos, scripts e favicon são relativos, permitindo a publicação em um subdiretório.

## Recursos visuais

- Imagem do hambúrguer gerada por IA.
- Favicon vetorial de hambúrguer nas cores da marca.
- Fontes Barlow Condensed e DM Sans, distribuídas com as respectivas licenças OFL em `assets/`.
